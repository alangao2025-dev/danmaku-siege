# 弹幕攻城战 · 赤焰 vs 苍蓝（抖音直播弹幕游戏原型 v2）

纯网页 Canvas 2D，没有任何图片/音频素材文件：角色、城堡、图标在启动时用代码绘制并缓存成帧，音效用 WebAudio 实时合成。

```
public/          游戏画面（直播时用直播伴侣采集这个窗口，按 H 隐藏右侧面板）
  js/config.js   数值：兵种、礼物、城堡血量、对局时长
  js/art.js      程序化美术：6 种兵 × 行走/攻击动画、城堡（4 档损坏）、礼物图标
  js/scene.js    黄昏战场背景、云、飞鸟、萤火、旗帜
  js/game.js     对局逻辑、单位 AI、大招、计分
  js/render.js   渲染与 HUD（血条、能量条、贡献榜、礼物横幅、结算领奖台）
  js/fx.js       粒子、冲击波、闪电、震屏
  js/sfx.js      合成音效
  js/main.js     主循环、机器人观众、模拟面板、后端 WebSocket
server/          本地后端：接收直播间事件 → 去重 → WebSocket 推给游戏
tools/           开发用：无浏览器截图（shot.mjs）、数值平衡（balance.mjs）
```

## 玩法
| 观众操作 | 效果 |
| --- | --- |
| 弹幕 `1` / `2` | 加入赤焰军 / 苍蓝军 |
| 弹幕 `冲` | 派出头顶自己昵称的士兵 |
| 弹幕 `剑` / `弓` / `法` | 切换职业并出兵 |
| 弹幕 `666` | 全军士气：攻击 ×1.5、移速提升 6 秒（每队 14 秒冷却） |
| 点赞 | 修复己方城墙 |
| 💗小心心 / 🌹玫瑰 / 🍩甜甜圈 / 🚀火箭 | 3 个精英兵 / 骑士 / 从天而降的石巨人 / 巨龙 |

击杀和送礼积攒能量，满了自动放大招（赤焰「陨石天降」、苍蓝「雷霆审判」）。最后 30 秒进入决战，伤害 ×1.5。3 分钟一局，推倒对方城堡或时间到时城堡血多者胜，结算显示领奖台和 MVP。

## 本地运行
```bash
npx serve public                 # 起网页，浏览器打开 http://localhost:3000
```
默认纯本地运行，右侧面板模拟直播间（机器人观众 + 手动发弹幕/送礼）。点一下画面开启音效。

连后端：
```bash
cd server && npm install && npm start      # :8080
# 浏览器打开 http://localhost:3000/?ws=ws://localhost:8080
npm run mock                               # 另开终端模拟观众刷屏
```

## 开发工具（本机无浏览器时检查画面）
```bash
cd tools && npm install
node shot.mjs /tmp/shots 3,30,90     # 在 Node 里跑真实逻辑和渲染，按秒数截图
node balance.mjs 12                   # 只跑逻辑，打印一局的城堡血量和兵力变化
```

## 接入抖音官方「直播小玩法」
同 v1：在 `server/index.js` 补全验签 `verifyDouyin`、字段转换 `fromDouyin`、礼物 ID 表 `GIFT_ID_MAP`，字段以开放平台文档当前版本为准。游戏只认统一事件格式，不用改。
